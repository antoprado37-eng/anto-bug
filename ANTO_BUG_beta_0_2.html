⚙️ ¿Qué pasa si falla la conexión?

El servicio puede estar caído, cambiar su formato o bloquear la consulta desde algunos navegadores. Si pasa, ANTO BUG no inventará resultados. «CONECTADO» solo significa que la API respondió, no que una sala se pueda abrir.

Prueba avanzada: pegá una respuesta JSON de códigos. Se marcará como PRUEBA MANUAL, nunca como conexión en vivo.
